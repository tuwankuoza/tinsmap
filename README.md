# TINSMAP · TINS Stakeholder Mapping

Prototipe sistem pemetaan stakeholder untuk Divisi Corporate Secretary, dibuat untuk kompetisi inovasi BIGMIND 2026 (kategori Corporate System and Ways of Working).

- `index.html`: halaman beranda
- `tinsmap.html`: dashboard (Ringkasan Eksekutif, Stakeholder Analysis, Proposal Bantuan, Rekapitulasi Biaya, Isu & Perizinan, Audit Trail)

Semua data di prototipe ini adalah **data contoh**. Nama stakeholder, penerima bantuan, dan nomor dokumen disamarkan; angka pagu, tenggat izin, dan status proposal bersifat ilustratif.

Situs statis tanpa build: buka `index.html` di browser, atau aktifkan GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
